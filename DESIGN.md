# Design Spec: Willow105 Grid Heatmap Visualization

## 1. Overview & Presentation Context
- **Purpose**: Bridge abstract quantum circuit synthesis (Dicke state Givens cascade) with physical hardware topology for the DuQuantum Google challenge presentation.
- **Slide Placement**: Occupies the left ~60% of a 16:9 presentation slide on a pure white / light background (`#FFFFFF`).
- **Export Formats**: Vector SVG (`assets/willow105_heatmap.svg`) and high-resolution 2x/300 DPI raster (`assets/willow105_heatmap.png`).
- **Generator Script**: Standalone, reproducible CLI script at `scripts/plot_willow_grid.py`.

---

## 2. Grid Geometry & Orientation
- **Device Layout**: Real Google Willow architecture (105 physical qubits, 182 native couplers) derived from `cirq_google.engine.virtual_engine_factory.create_device_from_processor_id('willow_pink')`.
- **Coordinate Space**: Native `cirq.GridQubit(row, col)` integer grid (rows 0 to 12, cols 0 to 14).
- **Lattice Outline**: Natural diamond/octagonal silhouette, with couplers aligned purely horizontally and vertically along coordinate axes.
- **Aspect Ratio**: Compact balanced framing (~4:3 or ~1:1 active grid bounding box) leaving space at the bottom for a clean legend.

---

## 3. Visual Styling & Color Hierarchy

### Color Palette
- **Background**: Pure white (`#FFFFFF`) / canvas neutral.
- **Working Qubits**: Clean white circular nodes (`#FFFFFF`) with crisp, thin dark slate borders (`#334155`, width 1.2pt).
- **Dropout Qubits**: Soft muted gray fill (`#CBD5E1`), borderless, cleanly receding into the background.
- **Couplers (Active CZ)**: Monochromatic single-hue gradient in **deep indigo/navy** (`#C7D2FE` for low error $\to$ `#1E1B4B` for high error). Linear or log-scaled to calibration infidelity ($p_{CZ}$).
- **Dead Couplers (Dropouts)**: Faint dotted light-gray lines (`#CBD5E1`, linestyle `':'`, width 1.0pt) preserving total lattice topology context without visual clutter.
- **Selected Chain ($N=12$)**:
  - High-contrast **warm amber/coral** stroke (`#EA580C` / `#F97316`, width 3.5pt, solid).
  - Selected nodes filled with matching amber (`#EA580C`), dark border (`#9A3412`).
  - Subtle `Start` and `End` endpoint annotations cleanly placed near the terminal qubits (8pt sans-serif font).

---

## 4. Benchmark Noise Data & Chain Selection
- **Noise Sampling**: Standard benchmark harness from `src/noise_models.py`:
  - Qubit dropout rate: 1%
  - Coupler dropout rate: 1%
  - CZ Pauli error median: $2.5 \times 10^{-3}$, log-normal spread $0.5$.
- **Seed**: Fixed deterministic random seed that samples a representative chip state featuring 2–3 localized dropouts and coupler dropouts.
- **Pathfinding**: Generated by running `src.willow_utils.find_best_linear_chain(graph, length=12)`, illustrating how the pruned branch-and-bound DFS naturally routes around high-error couplers and dropouts.

---

## 5. Typography, Annotations & Legend
- **Slide Title**: None embedded in the figure (handled directly by the presentation deck).
- **Legend & Colorbar**:
  - Horizontal bottom ribbon.
  - Left side: 4 swatch items:
    1. Working Qubit (white circle, slate stroke)
    2. Dropout Qubit (soft gray filled circle)
    3. Missing / Defective Coupler (dotted light-gray line)
    4. Selected 12-Qubit Chain (amber node + stroke)
  - Right side: Compact horizontal colorbar for CZ error rate ($p_{\text{CZ}}$) ranging from $\sim 10^{-3}$ to $\sim 10^{-2}$.
- **Font**: Clean modern sans-serif (`DejaVu Sans`, `Arial`, or standard Matplotlib sans-serif), minimum 8pt for readability at video scale.
